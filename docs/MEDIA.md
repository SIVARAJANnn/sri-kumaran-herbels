# Media and provenance

The project contains original product photographs supplied for the Sri Kumaran Herbals showcase and supplied product-video clips. The runtime consumes WebP sequences generated from those clips rather than playing video with audio.

## Active media

- Registry: `soap-scroll-studio/dist/media.json`
- Source archives: `soap-scroll-studio/videos/supplied-20261106075400335/`
- Integrity report: `soap-scroll-studio/supplied-video-report.json`
- Active frame batch: `soap-scroll-studio/dist/frames/supplied-20261106075400335/`

Each of the six clips yields 190 frames at 24 fps in two variants, for 2,280 active frame files. The integrity report preserves the original source filenames, source identifiers, and SHA-256 digests. Its recorded source directory describes the original workstation; the current tools default to the bundled archives, so that workstation path is not required.

The website retains a proportional central view of the supplied frames, with a small vertical adjustment for Charcoal. The archived MP4s and full WebP frames remain unchanged. The display crop excludes visible corner graphics; it does not provide watermark-free source exports or remove invisible SynthID metadata.

README screenshots were copied from the existing browser verification captures. The desktop opening and Avarampoo capture show the current proportional view; the collection capture shows the packaging grid. The mobile capture shows the Charcoal chapter on a narrow viewport. Full verification notes remain in `soap-scroll-studio/qa/`.
